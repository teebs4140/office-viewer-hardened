# Office Viewer (Hardened Fork)

> **Work in progress.** Not ready for general use yet. Installation, security and change notes will be added before the first release.

A cut-down fork of [Office Viewer](https://github.com/cweijan/vscode-office) 4.2.0 by Weijan Chen, released under the MIT License (see [LICENSE](LICENSE)). It keeps only the viewer for:

- CSV / TSV
- Excel (`.xlsx`, `.xlsm`)
- Word (`.docx`, `.dotx`)
- PDF

The Markdown editor, archive viewer, Git history, REST client, telemetry and the other upstream features have been removed. The fork uses its own extension and editor IDs, so it can be installed alongside the upstream extension.

This fork is not affiliated with or endorsed by the upstream author.
